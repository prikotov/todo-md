# Changelog

## [0.0.11] — 2026-08-20

### Fixed
- Точечный `validate <файл>` резолвит `depends_on`/`epic` по всему дереву задач проекта (включая `done/`, `cancelled/`, `backlog/`) — без ложных ошибок «references unknown ID»; валидируются по-прежнему только переданные файлы
- `set <ID> f1=v1 f2=v2 ...` применяет все присваивания одной атомарной записью (все или ничего, с rollback); аргумент без `=` и комбинация `status` с другими полями — явная ошибка вместо молчаливого игнорирования

## [0.0.10] — 2026-08-09

### Fixed
- Пустой `assignee` разрешён до начала работы и для отменённых задач; исполнитель обязателен только для статусов фактической работы и завершения

## [0.0.9] — 2026-08-09

### Added
- Сравнение todo-md с BMAD, Spec Kit и OpenSpec

### Changed
- Заголовки задач и эпиков приведены к формату «русский термин (English term)»
- Уточнены правила формулирования проблемы в Human Brief
- AI-комментарии в шаблонах задач и эпиков сделаны содержательнее и приведены к единому формату

## [0.0.8] — 2026-07-31

### Added
- HTML dashboard (`todo-md dashboard`) с визуализацией доски
- JSONL export (`todo-md export-jsonl`) для машинной обработки
- Валидация ссылок `depends_on` и `epic` — проверка существования целевых задач
- Lifecycle date fields: `due`, `started`, `completed`, `cancelled`
- Валидация формата datetime в Change History согласно DATES.md
- Кросс-проверка локального времени и Unix timestamp
- Команды атомарных переходов: `start`, `review`, `done`, `cancel`, `backlog`
- Валидация полей `author` и `assignee`
- Сводный анализ идей и аудит-роадмап (research)

### Changed
- Формат lifecycle-дат: локальное время + UTC timestamp
- Уточнена логика группировки эпиков в описании доски

### Fixed
- Закрыт незакрытый bash code block в документации
- Убран лишний пустой перевод строки после изображений в заголовке
- Убрана битая ссылка на несуществующий MODELS.md
