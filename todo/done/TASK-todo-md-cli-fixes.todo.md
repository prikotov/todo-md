# TASK-todo-md-cli-fixes: Починить ложные ошибки validate по одному файлу и молчаливое игнорирование лишних аргументов set

## 0. Простое описание (Human Brief)

### Проблема простыми словами (Problem)
- `validate` одного файла ругается на `depends_on`, ссылающийся на задачу в `done/`, — хотя доска валидна целиком.
- `set` с несколькими присваиваниями молча применяет только первое и завершается успешно — пользователь уверен, что все поля записаны.
- Оба случая обнаружены при закрытии TASK-todo-md-dashboard-generator: они сбивают с толку и провоцируют лишние команды.

### Варианты или путь решения (Solution Sketch)
- Для `validate`: строить индекс ID (`buildIdIndex`) по всему дереву задач проекта, а не только по переданным целям; валидировать — только целевые файлы.
- Для `set`: применить все `field=value` аргументы подряд; если множественное присваивание не поддерживается по дизайну — завершаться с ошибкой и перечислением проигнорированных аргументов.

### Ожидаемый результат (Expected Result)
- Точечная валидация файла с зависимостью из `done/` проходит без ложных ошибок.
- `set ID f1=v1 f2=v2` либо применяет оба поля, либо явно падает — молчаливое игнорирование исключено.

## 1. Концепция и Цель (Concept and Goal)

### История (User Story)
> Как разработчик, я хочу, чтобы точечный `validate` не давал ложных ошибок по зависимостям, а `set` не терял аргументы молча, чтобы CLI-команды можно было безопасно chaining-ить в одну строку.

### Цель по SMART (Goal)
Исправить две ошибки CLI в `src/bootstrap.php`: (1) `cli_validate` строит `idIndex` только из переданных целей — расширить до всего дерева задач; (2) `cli_set` применяет первый `field=value` и игнорирует остальные — применить все либо вернуть ошибку. Оба случая покрыты тестами.

## 2. Контекст и Границы (Context and Scope)
*   **Где делаем:** `src/bootstrap.php` (`cli_validate`, `cli_set`), при необходимости `src/TodoMd/Parser.php` (`buildIdIndex`), `tests/`.
*   **Текущее поведение:**
    *   `php bin/todo-md validate todo/<file>.todo.md` → `error: depends_on references unknown ID: <ID>` для зависимости, лежащей в `done/`; `validate todo/` при этом проходит.
