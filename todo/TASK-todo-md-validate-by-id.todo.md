# TASK-todo-md-validate-by-id: Валидация задачи по ID

## 0. Простое описание (Human Brief)

### Проблема простыми словами (Problem)
- Агент может найти задачу в статусной папке, затем ошибочно проверить сконструированный путь `todo/<ID>.todo.md`; валидатор при этом завершался успешно, не проверив файл.

### Варианты или путь решения (Solution Sketch)
- Разрешить передавать валидатору ID и находить файл по всему дереву `todo/`.
- Ошибочно переданный ID или путь завершать с кодом `1`.

### Ожидаемый результат (Expected Result)
- Проверка конкретной задачи не зависит от её текущей статусной папки и не даёт ложного успешного результата.

## 1. Концепция и Цель (Concept and Goal)

### История (User Story)
> Как пользователь `todo-md`, я хочу валидировать задачу по ID, чтобы её перемещение между статусными папками не ломало команду проверки.

### Цель по SMART (Goal)
- Добавить поддержку `validate <ID>`, диагностику отсутствующих целей, документацию и тесты в одном PR.

## 2. Контекст и Границы (Context and Scope)
- В scope: CLI `validate`, документация его вызова, fixture-тесты и dev-зависимость с правилами Git workflow.
- В scope: восстановление корректной зависимости завершённого исследования в существующей задаче Kiro.
- Out of scope: изменение формата задач и автоматическое перемещение файлов.
