# TASK-todo-md-cost-tracking: Поля оценки стоимости в токенах для задач и эпиков

## 1. Concept and Goal (Концепция и Цель)
### Story (User Story)
> Как владелец проекта, я хочу видеть план и факт стоимости задач в токенах, чтобы оценивать реальную стоимость разработки и управлять бюджетом.

### Goal (Цель по SMART)
Добавить в front matter задач (TASK) и эпиков (EPIC) поля для оценки стоимости в токенах: plan и fact. Позволит собирать статистику по стоимости разработки через AI-агентов.

## 2. Context and Scope (Контекст и Границы)
*   **Где делаем:** `docs/todo-md/templates/task.md`, `docs/todo-md/templates/epic.md`, возможно `docs/todo-md/reference/` (новый справочник по полям стоимости).
*   **Текущее поведение:** Нет полей для оценки стоимости. Нельзя отследить, сколько стоит задача/эпик.
*   **Границы (Out of Scope):**
    *   Не делаем автоматический подсчёт токенов (агенты пока не могут сами заполнять).
    *   Не делаем конвертацию в деньги на уровне шаблона (модель фиксят отдельно).

## 3. Requirements (Требования, MoSCoW)
### 🔴 Must Have (Обязательно)
- [ ] Поля в front matter task.md: `cost_plan` (оценка в токенах), `cost_fact` (факт в токенах).
- [ ] Поля в front matter epic.md: `cost_plan` (суммарная оценка), `cost_fact` (суммарный факт).
- [ ] Формат: число (integer), единица — токены.
- [ ] Поля опциональные (пустые при создании).
- [ ] Описание полей в справочнике (GLOSSARY или отдельный COST.md).

### 🟡 Should Have (Желательно)
- [ ] Комментарий в шаблоне: «заполняется по завершении, источник — billing/API usage dashboard».
- [ ] Пример заполнения в шаблоне.

### 🟢 Could Have (Опционально)
- [ ] Конвертация в рубли/доллары при указании модели и цены за 1M токенов (формула, не автоматика).

### ⚫ Won't Have (Не будем делать)
- [ ] Автоматический сбор токенов из API провайдеров.
- [ ] Дашборд стоимости.

## 4. Implementation Plan (План реализации)

## 5. Definition of Done (Критерии приёмки)
- [ ] В шаблонах task и epic есть поля для plan/fact стоимости в токенах.
- [ ] Поля описаны в справочнике.

## 6. Risks and Dependencies (Риски и зависимости)
- Агенты могут не заполнять поля автоматически — нужна дисциплина или отдельный инструмент.

## 7. Comments (Комментарии)
Зачем в токенах, а не в деньгах: цена токена зависит от модели. Фиксируем в токенах → при смене модели пересчёт тривиален. В деньги переводим при фиксации модели и цены.
