# Список LLM-моделей (Models)

Модели указываются **в составе участника** — в полях `author`, `assignee`, `reviewer`, `approver`, `consultants`, `informed` задач и эпиков. Отдельного поля `model` в front matter нет.

## Формат участника

```
<роль> (<агент>[@<модель>])
```

- `роль` — функциональная обязанность (`Бэкендер`, `Продакт`); см. [ROLES.md](./ROLES.md).
- `агент` — lowercase-идентификатор инструмента (`pi`, `codex-cli`); см. [AI_AGENTS.md](./AI_AGENTS.md).
- `модель` — опционально; lowercase-идентификатор с опциональным тегом: `[a-z0-9][a-z0-9.:_-]*`.

Разделитель `@` выбран вместо `/`, чтобы не путать с нотацией `provider/model`.

## Модель и роли

Модель закреплена **за ролью** — в конфиге проекта хранится профиль роли (провайдер, модель, уровень мышления), например `config/chains.yaml`. Задача фиксирует **срез**: кто и на какой модели реально выполнял работу. Конфиг ролей меняется со временем, а записи участников в done-задаче остаются исторической правдой.

Правила заполнения:

- Указывать модель **рекомендуется** для всех участников — постановщика, исполнителя, ревьювера, консультантов.
- Источник истины для агента — окружение его харнесса (например, `PI_MODEL` / `PI_PROVIDER` у pi) или профиль его роли, а не «самоописание» модели: LLM угадывает свою модель недостоверно.
- Запись без модели (`Продакт (pi)`) остаётся валидной — для участников, чья модель не важна или неизвестна.

## Валидация

Валидатор `todo-md validate` проверяет модель в составе каждого участника:

- формат (lowercase-идентификатор с опциональным тегом);
- вхождение в канонический список (см. выше) — нарушение выводится как warning, в режиме `--strict` или `strict: true` — как error;
- модель опциональна — запись участника без `@модель` валидна всегда.

Список можно заменить или расширить через конфиг `.todo-md.php` (`models`) — см. [CONFIG.md](./CONFIG.md). Новые модели, которых нет в списке, добавляйте в конфиг своего проекта.

## Пример

```yaml
author: Продакт (pi@k3.1-pro)              # постановщик на Kimi
assignee: Бэкендер (pi@glm-5.3-flash)      # исполнитель на GLM Flash
reviewer: Ревьюер (pi@huihui-ai:pi-100k)   # ревью на локальном ollama
```
